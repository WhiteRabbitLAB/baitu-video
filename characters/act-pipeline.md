# 角色表演:生图当美术,代码当引擎

游戏为什么能把美术和代码结合好:美术画素材,代码只管摆放、换帧、动关节、补光。纯代码画细节多的人物做不细(孙悟空纯代码五版样片被否),
所以人物交给生图,动作交给代码。作者的本地试验场 `game-art/`(2026-10-06/07)全程跑通;下文提到的 `game-art/` 文件不在开源版里,方法照写。

## 1. 先列动作衔接表(../transitions.md §B)
出图前定好:要哪些姿势、相邻姿势之间变什么、大变化补什么过渡。

## 2. 生图(决策者 / 美术用自己的生图工具出,我们写提示词)
- **A 三视图**定稿(正 / 侧朝右 / 背),之后每张都拿它当参考图。
- **关键姿势**每张单独生成:侧身朝右、两脚并拢站在画面 94% 处、腰带与下摆与参考一致、道具完整不裁切。
- 提示词四规矩:纯绿底 #00B140(白色衣物不能用白底)、无描边平涂、光的方向与场景一致、不画地面与投影;把场景色板写进去。
- **走路 / 跑这类连续动作不靠生图**:实测要求后四帧换腿,修正提示词写到逐帧,模型仍画成同一条腿在前 ⇒ 交给代码骨骼。【能力边界 2026-10;换了新的生图模型先用同一条提示词重测,能换腿了就放开】

## 3. 抠图对齐(game-art/prep-poses.mjs、rig-prep.mjs)
- 抠绿用**从画面边缘漫水**:只去掉与外部连通的绿,角色身上的绿色(P2 薄荷色眼珠)不受影响;再按与绿幕色距离 < 70 抠掉被手臂/道具围住的小块绿底;边缘一圈去绿溢。
- 所有姿势**同一个缩放系数**(按站直总身高对上走路帧),不逐张缩放,否则身高会跳。
- 对齐:脚底 → 地面线;两只靴子的水平中心 → 代码腿站定时的靴子中心。
- 切身体零件(走路用):去掉下摆以下 + 下摆附近的裤子色;去色规则只管下摆附近,管宽了会挖掉袖子暗部(实抓)。尾巴等附件在切口落在被遮挡处的位置单独切出,绕根部转。

## 4. 代码骨骼腿(game-art/scene.html 的 legPose / drawLeg / hero)
- 腿长 L1+L2 = 髋到脚踝的站直高度:**撑地腿伸直**,髋高由直腿算出(倒摆),两腿都撑地时取低的 ⇒ 起伏自然产生(约身高 2–3%)。
- 着地(周期前 60%):脚踝随地面匀速后移(相对身体速度 = 地面速度 ⇒ 不滑步);开头 12% 脚跟着地放平;72% 后脚跟抬起、绕脚尖蹬地。
- 摆动(后 40%):前半程提脚弯膝,后段放下、腿伸直往前踢,落地前脚尖翘起。
- 两腿相差半个周期;远侧腿颜色 ×0.72。
- 减速停下:步频不变、步幅 × k(k = 当前速度/全速)⇒ 停下时两脚收到身体下方;背景按 `X(t)` 距离卷动。
- 颜色从生图取样,腿型照生图画(灯笼裤、金带、靴子),比生图原腿略粗才压得住身体。

## 5. 上半身二级动作
走路前倾约 0.045 rad + 随步晃;尾巴比身体慢半拍摆;站定后呼吸(纵向 ±0.7%)。

## 6. 姿势切换
- 站定后用整张生图姿势(带它自己的腿);停下那一刻代码腿刚好站直并拢,切过去不露接缝。
- 切换瞬间到位一弹;惊讶加 10px 一跳(0.28s)。
- 大变化必须有过渡姿势(试验里 P2→P3 硬切,被指出「应该提前想好如何衔接」)。

## 7. 按场景补光(风格文件里写参数)
调色压进场景光 → 轮廓光 → 局部光源 → 投影 → 与场景同一道后期。

## 8. 验收
连续帧看着地脚对地面(不滑)、左右腿交替(远侧腿暗)、姿势切换处不跳位、放大看抠图边缘无绿边、角色身上的绿色没被抠穿。

## 已知天花板
- 姿势之间是切换,不是补间;流畅度靠过渡姿势数量。
- 手臂、道具的连续动作目前没做骨骼(要做就把手臂+道具切成单独图层)。
- 只验证了一个角色、一种风格、侧面视角。
