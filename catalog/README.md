# 目录:使用者从这里进

做一期片子先回答四个问题,目录给出推荐组合(片型 × 场景 × 画风):

1. **你想做什么?** → [purposes.md](purposes.md)(目的:科普讲解 / 教学教程 / 评测对比 / 故事纪实 / 观点表达 / 清单盘点 / 资讯速览)
2. **什么行业?** → [industries.md](industries.md)(健康营养 / 科技 AI / 自然科学 / 人文历史艺术 / 社科心理法律 / 财经商业 / 教育学习 / 职场技能 / 生活)
3. **想要什么感觉?** → [../styles/INDEX.md](../styles/INDEX.md)(看缩略图选;画风会长期增加,路线图见 [../styles/ROADMAP.md](../styles/ROADMAP.md))
4. **发在哪些平台?** → 横版平台(YouTube、B 站等)只出横版;竖版平台(抖音、小红书等)只出竖版,竖版按竖屏重新排版(见 ../pipeline.md §0)

参考了哪些热门作品、它们能不能转成我们的模板,见 [references.md](references.md)。

## 状态标记(全目录通用)
| 标记 | 意思 | 判定 |
|---|---|---|
| ✅ 可做 | 已有成片或几乎相同的组合跑通过 | 有案例(写明哪一期) |
| 🧪 需测试 | 代码 + 生图 + 公版素材能做,但还没出过样片 | 做一段样片、决策者看过 ⇒ 升 ✅ |
| ⛔ 暂不可做 | 依赖我们没有的能力 | 真人出镜、实拍实验、大量授权素材、重 3D、真人采访 |

⛔ 和「纯代码做不细」这类判断都属于**能力边界**,不是永久的:能力补上(换了更强的模型、接入了某种生成工具)就重测,通过就改成 🧪 或 ✅。
每次做完一期、或试出一种新组合,回来改状态。

## 硬线:能不能做的判断
画面能不能**全部**用「代码画 + 生图(人物、插图)+ 公版素材 / 自己生成的素材」做出来。
- 能 ⇒ ✅ 或 🧪。
- 核心画面必须是真人、实拍、授权影视素材 ⇒ ⛔;常见的转换办法是「保留它的叙事结构,画面换成我们能做的」(例:实拍实验 → 实验纪实动画重述)。
