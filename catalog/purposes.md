# 第一问:你想做什么(目的)

目的决定叙事骨架(片型)。同一个行业,科普和教学的骨架完全不同;同一个片型却能跨行业用。

| 目的 | 观众带走什么 | 热门参考(形式) | 我们的片型 | 状态 |
|---|---|---|---|---|
| **科普讲解** | 一个现象 / 机制终于懂了 | 回形针(纯动画信息图)、Kurzgesagt(扁平动画)、毕导(真人 + 图) | [mechanism](../formats/mechanism.md)、[experiment](../formats/experiment.md)、[case-file](../formats/case-file.md)、[spread-history](../formats/spread-history.md)、[evolution](../formats/evolution.md) | ✅ 营养 N3–N9 |
| **故事纪实** | 一段真实的人和事 | 小约翰可汗(写实素材混剪)、TED-Ed(每集换画风的动画故事) | [experiment](../formats/experiment.md)、[timeline-epic](../formats/timeline-epic.md)、[case-file](../formats/case-file.md) | ✅ N8、一部艺术通史长片 |
| **教学教程 · 用工具** | 学会一件具体的事 | 软件 / AI 工具教程(录屏 + 标注) | [howto-guide](../formats/howto-guide.md)、[story-method-test](../formats/story-method-test.md) | ✅ AI A2、A6 |
| **教学教程 · 学概念** | 一个抽象概念真正理解 | 3Blue1Brown(对象连续变形)、可汗学院(手写板书) | [concept-lesson](../formats/concept-lesson.md)(概念 → 直觉 → 推导 → 例题) | 🧪 骨架已写,还没出过样片;代码天然适合 |
| **评测对比** | 该选哪个 | 数码评测、AI 模型横评 | [product-review](../formats/product-review.md);[versus](../formats/versus.md)(A vs B 逐项) | ✅ A1;versus 🧪 骨架已写,还没出过样片 |
| **观点表达** | 换一个角度看问题 | 半佛仙人(表情包 + 素材 + 犀利文案)、Vox(资料拼贴论证) | 观点装进故事或实测:[story-method-test](../formats/story-method-test.md) | 🧪;纯论证散文是**反面例子**(A4 不合格) |
| **清单盘点** | 一张可截图的清单 | 「N 个……」「排行榜」 | [listicle](../formats/listicle.md)(钩子 → N 条各一个画面 → 总表) | 🧪 骨架已写,还没出过样片;适合竖版 |
| **资讯速览** | 最近发生了什么 | 新闻解读、周报 | [product-review](../formats/product-review.md) 的变体 | 🧪 低优先:决策者明确不想做纯新闻 |

## 怎么用
- 先选目的 → 看推荐片型 → 进行业表(industries.md)找场景 → 选画风。
- 想做的事在表里找不到:按最接近的一行起步,做完在这里加一行(写清参考作品、片型、状态)。

## 骨架已写、等第一部样片的片型
1. **concept-lesson 概念教学**:3b1b 那一路是代码的主场,教育类刚需。
2. **versus 对比评测**:评测类刚需,结构固定,容易模板化。
3. **listicle 清单盘点**:最适合抖音竖版。
