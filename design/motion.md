# 动效与材质

运镜、转场、节奏的参数与出处在 [camera-transitions.md](camera-transitions.md);本文件管文字出场、材质和场景里的小循环。

## 文字出场
- **手写**(钢笔、圆珠笔、毛笔、马克笔):逐字排版(按字体真实字宽);每字固定种子的微小不规则——角度 ±2°、上下 ±3% 字号、大小 ±4%、墨色 ±15%(档案风错落 ×1.4 更像人写);每个字从左到右擦出,一行按字数匀速写。**不用 SVG 位移滤镜**(毛边显糊)。
- **打字机**:逐字瞬间出现,墨色随机深浅,个别字略偏上/偏下;配打字音效。
- **红笔批注**:一笔一笔画出;正片叠底。
- **印章**:落下一下 + 油墨斑驳遮罩 + 轻微震动。
- **数字**:滚动 / 跳动时**只显示真实值**,不得闪出中间值或越界值。
- **弹出**(气泡、标签):轻微过冲回弹。
- **淡入上滑**(扁平):透明度 + 上移 12–20px。

## 镜头
- **段首横移**:同一张桌面 / 同一面墙移到下一块(纸面、看板场景的默认接法)。
- **推近 / 拉回**:推近正在讲的那块,讲完拉回全景(界面类场景)。
- **zoom punch**:切换瞬间轻微放大回弹,配节拍。
- **视差卷动**:多层按不同系数卷动,按「走过的距离」而不是时间(才能停下)。

## 场景内一直在动的东西(防止「图片之间的转场」)
每个场景至少 2–4 个小循环:光斑、颗粒、仪器曲线、迷雾、萤火虫、窗灯、纸张轻微起伏……取自这个场景自己的母题。

## 材质
| 材质 | 做法 | 用在 |
|---|---|---|
| 纸纹 / 牛皮纸 | 画布逐像素画一次,常驻复用 | 纸面拟物 |
| 胶片 / 纸面颗粒 | 预生成噪声贴图,overlay 6–9%,每秒换 12 次偏移 | 几乎所有画风 |
| 暗角 | 径向渐变压边 | 几乎所有画风 |
| 油墨叠印 | 正片叠底 | 红笔、档案红印刷、印章 |
| 台灯 / 窗光 | 光照渐变整幅相乘 | 纸面拟物 |
| 金边面板 | 渐变描边 + 内阴影 | 游戏拟物 |
| 网点(孔版印刷) | 每种油墨 21 档圆点图案,7px 网格,蓝 15°、粉 75°;`kit.tone(油墨, 深浅)` | 孔版印刷 |
| 油墨分版 + 套色错位 | 每种油墨一组、正片叠底;粉版固定偏 (3,-2)px,**不逐帧抖**;`kit.ink(油墨, 内容)` | 孔版印刷 |
| 印刷颗粒 | 纸色小点盖在墨上(不在纸上打洞),12 帧/秒换位;色块强档、字轻档 | 孔版印刷 |

## 机制动画(画面自己演一个过程)
- **生物富集粒子**:每粒「汞」是一个粉点,有自己的宿主链(水 → 小鱼 → 中鱼 → 大鱼);被吃的那一刻,猎物沿直线滑进捕食者嘴里缩没,它身上的粒子各自飞到捕食者体内一个固定位置(每粒每个宿主一组随机身体坐标,逐帧可复现)。「活得越久」时新粒子在大鱼体内一颗颗冒出来 + 年龄计数。画面角落常驻「示意 · 非实测」,后面紧接实测数据(第 11 期:FDA 均值点阵,一颗 = 0.01 mg/kg)。【我们】第 11 期。
- **撕标签**:锯齿边纸条盖在真名上,撕走时绕左上角卷起 + 上移 + 淡出(0.35–0.65 进度内淡完,飞出画面前就看不见),底下的真名(学名)随后显影。【我们】第 11 期。
- **翻包装**:横向压扁到 0 再展开(前半正面、后半背面),背面关键一行用荧光笔刷出来。【我们】第 11 期。
