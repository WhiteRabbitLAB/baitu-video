# 实拍素材进画面(公版 / 可商用的现成素材)

【能力边界更新 2026-10-10】引擎原本只画代码动画。现成的实拍素材(不是我们自己拍的)可以这样接进同一个页面,和动画叠层、转场、字幕、章节进度条共用一套。已在一部 13 分钟的整片里跑通。

## 素材从哪来、收什么
| 来源 | 许可 | 怎么拿 | 注意 |
|---|---|---|---|
| 政府机构公版影像(如美国国家公园管理局各公园的视频库、NASA、美国农业部) | 公版 | 页面里直接有 mp4 地址 | 常见只有 720p;每条页面写着拍摄地点,**用来核对画面是哪儿** |
| Wikimedia Commons | 只收 公版 / CC0 / CC BY;**不收 CC BY-SA**(会传染到成片) | `api.php?list=search&srsearch=<词> filetype:video` + `prop=imageinfo&iiextmetadatafilter=LicenseShortName\|Artist` 一次拿许可和作者 | 并发下载会 429,**一条一条下、请求间隔 2–3 秒、带联系方式的 User-Agent**;CC BY 要在简介署名 |
| Pexels | Pexels 许可(可商用、免署名) | 搜索页 curl 被挡,WebFetch 能读出编号;下载走 `pexels.com/download/video/<编号>/` | 很多是竖拍;标着地名不等于真是那儿(实测混进别国景点) |

**先远程抽帧再下载**:ffmpeg 直接读地址取 3 帧拼总览,逐张看内容、地点、有没有人脸 / 血腥 / 违规机位,再下整片。

## 必查的坑
- **违规机位**:目的地禁飞无人机,就不用高空俯拍素材(实测 Pexels 有一条从正上方高空俯拍、明显是无人机机位的);片子里讲规矩,画面不能自打嘴巴。
- **画面与口播 / 题注对得上**:用素材页写的拍摄地点核;认不出的不用。题注写原始标题里的年份与作者,不自己推断。
- **老照片可能是立体照片卡**(左右两张并排 + 卡纸):裁左半张,裁切比例实测;Commons 上同一批扫描有**文件名和内容对调**的,题注按卡片上印的原标题写。
- **录像里的人**:用公版录像可以,但避开正脸特写和受伤、血腥画面。
- **公版介绍片里夹着第三方版权画面**:政府机构的视频会插卫星地图(带 Google 标记)、他人照片;这些段落常是**渐变过渡**,场景切换检测(`select='gt(scene,0.3)'`)切不开,会和前后镜头算成一段 ⇒ 选中的段落再逐 3 秒抽帧核一遍(2026-10-11 第二部实拍片:一段「水下珊瑚」里混了 10 秒卫星地图)。
- **画面里烧着作者水印 / 人名字幕条**:CC BY 街拍常在角上打摄影师署名,机构片常有受访者字幕条 ⇒ 放大 + 把焦点锚到另一侧裁掉(`fy: 0` 裁底部),署名照样写进简介;实在裁不掉就不用。
- **Pexels 搜索页 curl 会被 Cloudflare 拦**:WebFetch 也不可用时,用浏览器扩展在 pexels.com 页面里 `fetch` 搜索页、从 HTML 抽 `/video/<slug>-<id>/` 和 `videos.pexels.com/video-files/<id>/…mp4`;文件 CDN 本机可直接下载 / 远程抽帧。页面 `"location"` 字段多是上传者所在地,**不能当拍摄地**,一律抽帧肉眼核。
- **Pexels 先远程看再下(第三部实拍片,2026-10-12)**:WebFetch 能读搜索页拿编号;`pexels.com/download/video/<编号>/` 的 302 跳转地址可以直接给 ffprobe / ffmpeg 读,每条在 10% / 50% / 90% 处各抽一帧拼总览图,看完再下。下载后统一转成 1920 宽(省掉 4K 原片的磁盘)。**标题里的地名也可能错**:一条标着港口小镇的素材,红色草顶房其实是法罗群岛托尔斯港;没写地点的素材画面题注一律标「示意」。用作钩子的那条最好能从上传者页面确认拍摄国(本地摄影师、说明里写了地点)。
- **矢量海图比位图海图更灵活**:讲地理时把公版海岸线(Natural Earth 1:10m / 1:50m)或 OpenStreetMap 海岸线、街道转成路径,页面逐帧画(海、海岸水纹、陆地、经纬线),镜头在图坐标里推拉;不用先出一张大 jpg。**在 OSM 街道图上标点之前先画一张带网格的底图**(每 200 图坐标一条线、标数字)对着看:按经纬度估的港口、裂缝位置曾整片偏离真实海岸线。
- **剪辑点只用一个机位**:同一段素材里取镜头前先做场景切换检测,镜头的「入点 + 时长 × 速度」不许跨过剪辑点(否则成片里会闪进下一个机位);素材太短就降速或换素材,别硬拖。

## 怎么进页面(逐帧确定)
1. **镜头表单一驻地**(一个 js 文件,页面和抽帧脚本共用):每个实拍镜头写 素材键、入点、速度、缩放起止、焦点、叠加层;时间挂在配音时间轴的句子上。
2. **抽帧脚本**按镜头表把需要的那一段抽成 `frames/<镜头>/%05d.jpg`(1920×1080,`-q:v 3`;竖拍素材 `crop=iw:iw*9/16:0:(ih-iw*9/16)*cy` 取横条;统一轻调色 `eq=contrast=1.04:saturation=1.06`;原片不够长时 `tpad` 定格并报警),参数没变的镜头跳过。约 1 万帧 ≈ 2.4 GB。
3. **页面用 SVG `<image>` 逐帧引用**,推拉用变换(亚像素平滑)。实测:每帧重建的 `<image>` 截图时不会空白;判定器先用「没有图片 → 必须全报空白」的阳性对照证明有效(第一次的判定器因为 SVG 属性没加引号测成全黑,阳性对照才抓出来)。
4. 嵌在动画里的小画框(老胶片、老录像)按原生尺寸抽,外面画胶片齿孔或白边相纸。

## 页面构建
场景源码可以分文件写,但**引擎 `fonts` 只扫页面 HTML**:外部 js 里的上屏字会漏切、悄悄回退字体。做法:构建一步把分文件的场景脚本内联进成片页,再跑 `fonts`。

## 配乐(制作中不能出声时)
不能试听就看响度曲线:`ffmpeg -af ebur128` 每 10 秒取一个 M 值,挑「平稳偏轻」的垫历史 / 叙述段,「有起伏」的让高潮对准片子的转折点;中间有长段近乎静音的曲子不用。几首曲子先各自 `loudnorm` 到同一响度再交叉淡化拼接,总长要**长过成片**(混音会循环背景乐,短了结尾会重新起头)。

## 档案背景叠法:动画为主、实拍压暗只在关键时刻浮现(2026-10-14)
和上面「实拍满屏当主画面」反过来:主角是光笔动画,实拍 / 历史照片当一层压暗的背景(参考一条 SpaceX 历程短片的做法,只学做法)。
- **预处理两版**(`prep.sh` 一类脚本,可重跑):主图(保留原调,世界坐标里「显影」)+ 背景版(`scale…crop=1920:1080,gblur=5,eq=saturation=0.22,colorbalance=bs=.07` —— 去色、偏冷、轻模糊);实拍片段同样去色偏冷后抽帧。
- **只在关键时刻出现**:每段实拍 / 背景照片写成 `[开始, 结束, 不透明度]`,进出各淡 0.6–1s;不透明度按情绪给(背景照片 .2–.4,实拍 .4–.6),上面再盖一张四周渐暗到底色的径向渐变(看不出边框)。
- **照片「显影」**:光笔先画框,照片在框里从 0 淡到 1,中段叠一层暖白光(`sin(k·π)`);第一张照片(曝光几个小时)用慢速幂次显影 + 先露一块「涂沥青的金属板」。
- **档案标签**:顶部居中三行 ——「● ARCHIVE · 历史影像」(红点呼吸)/ 名称 · 作者 · 年份 / 许可 · 收藏地。**不是当次事件的影像要写明**(「1947 年美军影像(同型火箭,不是 1946 年那一次)」「资料画面,拍摄年份未注明」);用现存照片做的原理演示(如按 RGB 拆分色片)要常驻一行「原理示意 · 不是当年的底片」(复核实抓)。
- **HUD 与字**:左上年份(换年时上滑淡入)、右上章节、左下展签(大字一句 + 小字「地点 · 年份 · 人」);顶部、底部各一条压暗渐变,亮照片上也看得清;世界坐标里的标签垫一块半透明暗底板。
- **检查工具的分组坑**:同一个父节点下的 `<text>` 会被合并成一串量框 ⇒ 年份、时码、字幕、档案标签每块各包一层 `<g>`,否则整组被当成横跨全屏的一串字,报「压在素材上」;照片的阴影底、显影光这类矩形加 `data-over`。
- **原声**:公版录音(如 NASA 舱内录音)在 narrate 之后用脚本叠进 narration.wav(起点从 timeline.json 算,页面原声字幕用同一个算法);混音的人声压低会同时压住配乐。
- **配乐要「燃」**:bgm 两首以上先各自 loudnorm 到 -18 再交叉淡化,把曲子的第一个大高潮对在片子的转折点(本期:火箭升空);`bgm.json` 增益 +3 dB(往期 -11 / -24 只是垫底)。不能试听就按 ebur128 曲线挑,交片时请决策者听音量。
