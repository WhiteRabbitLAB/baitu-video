# 字体目录(按书写来源)

选字原则:先问「**这个字是谁、在什么场合、用什么工具写上去的**」,再从下表挑;同一来源全片统一。
只收可商用开源字体(下表几乎都是 SIL OFL 1.1,例外单独注明),用时按本片用到的字子集化:`node <engine>/cli.mjs fonts <期>` 自动下载并切子集。画风用到的字体的下载地址与授权登记在 ../engine/fonts.json;新增字体要在那里加一条。
「实战」列是已在成片里用过的;没写的是候选,用前先出样张。

**坑:英文字体没有中文,中文会悄悄回退。** Special Elite、Space Grotesk、JetBrains Mono 都不含中文字形,写在同一个字体栈里的中文会落到栈里下一个中文字体,字重取「最接近的已加载字重」:只加载了 500/900 时,要 700 会落到 900,要 400 会落到 500(2026-10-07 核实 N4 打字标签、A1/02 等宽标签)。中文要是有书写来源(比如打字机),就**单独给中文指定字体**,别靠回退。

**坑:轮廓方向。** 站酷小薇「回」的内轮廓和外框同向,浏览器按非零规则把洞填实。检查用 `engine/tools/check-winding.py 字体.ttf 本片用字`(只查不改,按相对方向判断);它会把「笔画落在框里」的字(如思源宋体繁的直、真、面)误报成缺陷,所以报出来的字**必须在样张上放大肉眼核**,渲染才算数。`engine/tools/fix-winding.py` 写死了「外轮廓顺时针」,只适用于站酷小薇,拿去改别的字体会把整套字反向,可变字体还可能被改坏(2026-10-07 实测)。

## 多语言版本
同一画面出英文版时,**每个中文书写来源都要配一个英文对应**(手写对手写、打字对打字),不能让英文落到回退字体;
英文场景可单独一套布局(英文更长),锚英文句 / 词的时间。
