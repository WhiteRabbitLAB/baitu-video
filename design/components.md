# 组件目录

可复用的画面部件。每个组件写清:它承载哪种文字角色(../text-roles.md)、在哪些画风下怎么长、参考实现。
「参考实现」一列只说明这个组件最早出自哪一期(往期页面 2026-10-07 已清理,不要去找);要用就用 `engine/vc` 里的共享组件,没有的按本表描述新做并补进共享组件。

**共享代码(2026-10-07 起)**:手写逐字、打字机、R6 批注、印章、数字滚动、气泡、AI 对话框、终端窗口、章节进度条、段首横移、字幕已抽成 `engine/vc/`(说明见 `engine/vc/README.md`,演示页 `engine/vc/demo.html`)。新一期优先用它;下表的「参考实现」是抽取来源。下表里还没进共享代码的:便签 / 记录本、原文卡、仪器屏、时间轴、地图、统计图、章节卡、对比墙、照片 + 题注。
