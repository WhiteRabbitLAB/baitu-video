# A vs B comparison (id: versus) 🧪

中文:[versus.md](versus.md)

## In one line
Two (at most three) things compared head-to-head under **the same conditions**: what's compared, how, where each wins, and finally "which to pick when" — viewers take away a screenshot-able choice table.

## Topic signals
- Viewers really are torn between the two (two AI models / two methods / two foods), and the answer is "it depends".
- You can run a **same-condition test** yourself (same prompt, same material, same person), or have first-hand comparison data.
- Counter-examples: a walkover (no suspense, no comparison); only able to repeat someone else's benchmarks (that's product-review); pure news (the decision-maker doesn't want it).

## Narrative skeleton
| Paragraph | Role | Typical content | Share |
|---|---|---|---|
| 1 | Hook: one comparison image, conclusion first | Split screen, two results for the same task, "here's the difference" | 5% |
| 2 | Why compare, who's competing (one line each) | Two ID cards | 8% |
| 3 | The rules: same conditions, how it's scored | Task, material, scoring rubric on one screen | 10% |
| 4–6 | Round by round (about 3 rounds, one dimension each) | Each round: task → both results side by side → score → the scoreboard changes | 50% |
| 7 | Twist / limits (who wins under which conditions) | "With long texts, it flips" | 12% |
| 8 | Choice table: pick which when | One table, screenshot-able | 10% |
| 9 | A question for the comments | "Which would you pick?" | 5% |

## Required shots / through-line elements
- **Split screen + a permanent scoreboard**: scores change only after real results are in (the R4 rule).
- Each side has a fixed color for the whole video; the same position is always the same side.
- The raw test material (prompts, inputs) is archived verbatim and can be expanded on screen (the comparison-wall component).

## Transition preferences
Between rounds **slide-push** (panel page change, 0.5 s); ID cards enter with **blur-push**; reveals can use **jump-in** (push in about 2× from the same camera position). The scoreboard is always present — it's the through-line element.

## Fact and platform risks
- **Fairness is the first risk**: same version, same date, same parameters, written in an on-screen credit; say so if there were few runs ("3 runs each").
- Don't disparage brands or feature their trademarks as the main visual; only state test results.
- Prices and versions go stale: the credit says "data as of YYYY-MM-DD".

## Suitable scenes
Worth trying: terminal-tech (AI topics), info-cards, lab-dashboard (nutrition: blood sugar after two breakfasts).
