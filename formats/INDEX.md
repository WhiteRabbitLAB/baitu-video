# 片型库

片型 = 叙事骨架 + 段落节奏 + 必备镜头。和场景、画风无关:同一片型可以配不同场景(看场景库的「适配片型」)。
案例来自作者的两个频道(营养科普、AI 用法);片型本身不限话题。

|---|---|---|---|---|
| [experiment](experiment.md) | 真实实验纪实 | 一个离奇的真实实验:设计 → 结果 → 反转 → 怎么用 | 营养科普 ×2 | 整片 ×2(反馈最好) |
| [story-method-test](story-method-test.md) | 故事引出方法 + 实测 | 经典故事 → 可迁移的方法 → 实测 / 对比生成证明 → 清单 | AI 用法 ×2 | 整片 ×2(中英) |

## 反面例子(别这么做)
- **论证型散文**(一部讲「AI 让作品更好看,为什么也越来越像」的片子):全片讲道理、没有故事主线,结尾示范「看着不一样、主题清楚,但审美没了」——被判整片不合格。教训:观点要装进故事或实测里;**示范结果本身必须过关**,否则自我拆台。

## 新增片型
1. 复制 [_template.md](_template.md) 为 `formats/<id>.md`,填齐每一节。
2. 至少用一期样片(段 1–2)验证节奏;在上表登记,状态写「样片验证」。整片做完改「整片验证」。
3. 片型里**不写**画面世界、颜色、字体——那些属于场景和画风。
