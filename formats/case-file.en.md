# Wrongful-accusation investigation (id: case-file)

中文:[case-file.md](case-file.md)

## In one line
Something everyone believes, investigated like a case: where it came from, how it spread, what the evidence says, who the real culprit is.

## Topic signals
- A traceable source event (a letter, a paper, an ad) and a later twist.
- The ending lands on a real problem (the wrongly accused thing → what actually deserves attention is something else).

## Narrative skeleton (one finished video, 11 paragraphs, about 4:10)
| Paragraph | Role |
|---|---|
| 1 | The suspect appears + the counter-intuitive conclusion first |
| 2–3 | The source event (original + translation) |
| 4–5 | How the panic spread |
| 6–7 | Evidence: double-blind trials etc. |
| 8 | Twist (the truth about the source itself) |
| 9–10 | The local angle (its history at home / similar products) |
| 11 | The real problem + what to do |

## Required shots / through-line elements
- Case files / folders / evidence numbers throughout; every paragraph is like opening a new piece of evidence.
- Primary texts shown as they are (original + translation + highlighter).

## Transition preferences
Open the next file; push an exhibit from the desk toward the camera; a stamp closes a paragraph.

## Fact and platform risks
- A "it was a prank" twist needs a reliable source; word it as the fact sheet does.
- Don't whitewash the wrongly accused thing (its real problems still get mentioned).
