# 真实实验纪实(id: experiment)

## 一句话
讲一个离奇的真实实验:怎么设计的、结果是什么、为什么反直觉、我们能拿来做什么。

## 选题信号
- 有具体的人、具体的年份、具体的操作(「把同一份食物贴两种标签」「一群人自愿按配给吃半年」)。
- 结果反常识,且结论有边界(只是关联 / 样本小 / 自评无差异)——边界本身就是戏。
- 观众反馈最好的一类(作者的营养频道实测);比「某营养素的来龙去脉」更有戏。

## 叙事骨架(两部成片都是 13 段,3:40–3:50)
| 段 | 作用 | 例(一个「同样东西、两种标签」的实验) |
|---|---|---|
| 1 | 第 0 帧就是实验的核心画面 + 反常识一句 | 两份一样的东西、标签上的热量差好几倍、其实完全相同 |
| 2 | 谁、什么时候、招募 | 哪年、哪所大学、谁做的,招募传单,多少人 |
| 3–4 | 被试被告知什么(实验的「骗局」) | 两张标签 |
| 5 | 必要的背景机制(一段讲清) | 一种激素 / 一条生理通路 |
| 6 | 流程(时间轴) | 几次采血 / 几次测量 |
| 7 | 结果(全片主视觉) | 监护屏两条曲线 |
| 8–9 | 反转 / 边界 / 后续研究 | 自评无差异;后来的同类实验 |
| 10–11 | 延伸到相关现象 | 两三个相关现象 |
| 12 | 怎么用(2–3 条可截图的建议) | 三张便签 |
| 13 | 评论区提问 | |

## 必备镜头 / 贯穿元素
- **一件贯穿全片的「仪器」**:监护屏;体重曲线坐标纸 + 进度牌。结果段就是它的全屏时刻。
- 时间轴 / 流程图一次讲清实验设计。
- 不画真人肖像:名牌、编号卡、空座位、腕带。

## 衔接偏好
同一张桌面 / 同一面墙「段首横移」;贯穿仪器缩放进出。

## 事实与平台风险
- 区分「客观测量」与「自评」;关联 ≠ 因果;小样本写清人数。
- 曲线只有走向没有数值 ⇒ 示意形状 + 常驻「示意」角标。
- 自伤细节不进稿(实测:原始资料里有被试自残,只字不提)。网传数字查一手。

- 一部看板题材的续集:约 5:00;开头 10 秒回顾上一部、留下的问题,再接新实验;上一部的道具原样回来。
