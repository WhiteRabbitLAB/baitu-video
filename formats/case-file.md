# 冤案调查(id: case-file)

## 一句话
一个人人都信的说法,像查案一样:它从哪来、怎么传开、证据怎么说、真凶是谁。

## 选题信号
- 有一个可追溯的源头事件(一封信、一篇论文、一个广告)和后来的反转。
- 结尾能落到一个真问题(被冤枉的东西 → 真正该管的是另一样)。

## 叙事骨架(一部成片 11 段,约 4:10)
| 段 | 作用 |
|---|---|
| 1 | 嫌疑人登场 + 反常识结论先行 |
| 2–3 | 源头事件(原件 + 译文) |
| 4–5 | 恐慌怎么传开 |
| 6–7 | 证据:双盲试验等 |
| 8 | 反转(源头本身的真相) |
| 9–10 | 本土视角(这东西在国内的历史 / 同类产品) |
| 11 | 落到真问题 + 怎么做 |

## 必备镜头 / 贯穿元素
- 案卷 / 档案袋 / 证物编号贯穿;每段像翻开一份新证据。
- 一手原文原样呈现(英文原件 + 中文译文 + 荧光笔)。

## 衔接偏好
翻开下一份文件;证物从桌面推到镜头前;盖章收束一段。

## 事实与平台风险
- 「恶作剧」类反转要有可靠出处,口径照事实表。
- 被冤枉的东西也别洗白过头(它该有的问题照样要说)。

## 适配场景
