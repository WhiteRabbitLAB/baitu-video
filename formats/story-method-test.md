# 故事引出方法 + 实测(id: story-method-test)

## 一句话
用一个有意思的故事引出一个可迁移的方法,再用实测(或同条件对比生成)证明这个方法真的有用,观众带走的是一种思维和一张清单。

## 选题信号
- 有一个经典故事 / 人物 / 现象,能映射到今天的问题(一个心理学经典案例 → AI 会顺着你的暗示答;一位画家向另一种艺术借构图 → 提示词别只报风格名)。
- 方法能被实测:同一个工具,换个做法,结果明显不同。
- 适合「帮人用好某个工具」的频道,不限 AI:同样适用于摄影、写作、学习方法等。

## 叙事骨架(两部成片:35 段约 6′47″;约 9′40″)
| 部分 | 作用 | 例 |
|---|---|---|
| 钩子 | 第 0 帧就是反差结果 | 八张「某某画家风格」的图全长一个样 |
| 精简故事 | 只讲和方法有关的部分 | 故事里真正起作用的那个机制 |
| 方法 | 拆成几步 / 几个问题 | 拆构图的五个问题;哪些问题值得测 |
| 实测 / 对比 | 预注册方案 → 跑 → 按真实结果讲 | 六家模型实测;报名字 ×8 vs 拆成决定 ×8 |
| 结论 + 清单 | 可截图带走 | |

## 必备镜头 / 贯穿元素
- 实验记录本或对比墙贯穿:方案、原始结果、统计都在上面。
- 对比要「同 prompt / 同条件,只改一处」,并排放。

## 衔接偏好
故事段用档案 / 照片;方法段用图解;实测段回到记录本;结论回到开头的钩子画面(前后呼应)。

## 事实与平台风险
- 实测先预注册判定标准,跑完不挪门柱;结果和预想不同就照实改稿(实测:英文版重跑结果与中文不同,稿子据实改写)。
- 实测的原始对话全部存档;追加的测试要标明是追加。
- 公版图写真实年份;第三方素材标出处。
- 用法类内容必须有实测(决策者要求)。

## 适配场景
已验证:field-notebook、gallery-wall(各一部成片)。建议:case-file、lab-desk-1944(纸面类都合适)。

## 案例
- 一部心理学故事:钩子 → 精简故事 → 我们该怎么做 → 实测 → 结论(决策者认可的结构);中英两版,英文实测重跑。
- 一部艺术史故事:同一套方法拆构图,A/B/C 三组生成对比。
