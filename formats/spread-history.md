# 一样东西的传播史(id: spread-history)

## 一句话
一样东西(食物、作物、技术、习惯、流行词)怎么来、怎么扩散、改变了什么,最后落到今天怎么用。作者的营养频道用它讲过外来作物怎么进中国。

## 选题信号
- 有明确的「第一次」(年份 + 人 + 原文),有扩散路线,有一个反常识的转折(比如一种调料刚传进来时先被当成观赏植物)。
- 知识类频道要带实用价值:历史和实用大约各半(决策者的要求)。

## 叙事骨架(两部成片 11–12 段,3:00–4:00)
| 段 | 作用 | 例 |
|---|---|---|
| 1 | 反常识开场 + 「当成一局游戏 / 一段旅程」 | 「几百年前这道菜里根本没有它」 |
| 2 | 第一次出现(原文 + 年份) | 某年某部古书里第一次出现,原文一句 |
| 3–6 | 扩散:地点、原因、谁推动 | 某地拿它代替另一样东西 → 沿一条大河扩散 |
| 7 | 改变了什么格局 | 旧格局被改写,原来的同类被淘汰 |
| 8–9 | 科学 / 营养 | 它在身体里起什么作用;今天怎么挑、怎么吃 |
| 10–11 | 研究证据(写清只是关联) | 它和某种健康结果的关联 |
| 末 | 怎么吃(可截图的建议) | 落到怎么吃、怎么做更好 |

## 必备镜头 / 贯穿元素
- **一张地图**贯穿全片,东西走到哪、哪里亮起来(两部都用迷雾翻开)。
- 「历史时刻卡」承载一手原文(竖排刻本 + 朱笔圈点)。
- 计数器 / 资源栏,让「扩散」可量化。

## 衔接偏好
地图平移到下一个地点;每段解锁一种新机制(不重复)。

## 事实与平台风险
- 地图只示意:只标省名,不画行政边界与国界。
- 家族记载、传说要用转述口径(「据他家后人记载」)。
- 两物同名要分清(古籍里的同名植物常常不是一种);「养活几亿人」类大数字要核原始研究(实测:一个流传很广的数字被一手研究更正了)。
