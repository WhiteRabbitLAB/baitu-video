# Story → method → real test (id: story-method-test)

中文:[story-method-test.md](story-method-test.md)

## In one line
Use an interesting story to introduce a transferable method, then prove with a real test (or controlled generation) that the method works; viewers take away a way of thinking and a checklist.

## Topic signals
- A classic story / person / phenomenon that maps onto today's problem (a classic psychology case → AI goes along with your hints; a painter borrowing composition from another art form → don't just name a style in your prompt).
- The method can be tested: same tool, different approach, clearly different results.
- Suits any "help people use a tool well" channel, not only AI: photography, writing, study methods.

## Narrative skeleton (two finished videos: 35 paragraphs, about 6′47″; about 9′40″)
| Part | Role | Example |
|---|---|---|
| Hook | Frame 0 is the contrasting result | Eight "in the style of painter X" images that all look the same |
| Short story | Only the part relevant to the method | The mechanism that was really at work in the story |
| Method | Broken into steps / questions | Five questions for breaking down a composition; which questions are worth testing |
| Test / comparison | Pre-registered plan → run → report the real result | Six models tested; naming a style ×8 vs breaking it into decisions ×8 |
| Conclusion + checklist | Screenshot-able takeaway | |

## Required shots / through-line elements
- A lab notebook or comparison wall throughout: plan, raw results and stats all on it.
- Comparisons are "same prompt / same conditions, change one thing", side by side.

## Transition preferences
Story paragraphs use archives / photos; method paragraphs use diagrams; test paragraphs return to the notebook; the conclusion returns to the opening hook (bookends).

## Fact and platform risks
- Pre-register the pass criteria, don't move the goalposts; if results differ from expectations, rewrite the script to match (measured: the English re-run gave different results from the Chinese one, and the script was rewritten accordingly).
- Archive all raw test conversations; label any extra tests as extra.
- Public-domain images carry their real year; third-party material is credited.
- How-to content must include a real test (decision-maker's requirement).

## Suitable scenes
Validated: field-notebook, gallery-wall (one finished video each). Suggested: case-file, lab-desk-1944 (any paper scene).

## Cases
- A psychology story: hook → short story → what we should do → test → conclusion (the structure the decision-maker approved); zh and en versions, the test re-run in English.
- An art-history story: the same method for breaking down composition, A/B/C generation comparisons.
