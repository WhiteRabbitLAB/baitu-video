# 体育转播(id: broadcast)

## 渲染语言
电视体育转播的包装:**夜场看台**(深蓝黑底、虚化人群色点、顶上一排泛光灯)+ **转播包装条**(深蓝比分板、黄色时间标签、白底裁判条、场边 LED 广告板)+ 画面底部一条草皮。
无描边平涂,圆角 6–14px;比分板上半块一层淡高光,两侧各一根队色竖条。
**比喻是「比赛」**:两组 = 两支队,结果 = 比分,统计判定 = 裁判条,资助方 = 场边赞助广告,其他研究 = 「其他赛区」比分,复核 = 「赛后复核」。适合「A 和 B 正面比、结果接近」的对照试验题。
**颜色即含义**:两队各一种颜色(`c.home` 橙 #FF7A2F / `c.away` 蓝 #3D8BFF,页面里第三队可以用 `c.red`);**黄 #FFD23F 只给转播包装**(时间标签、裁判、赞助板、强调);其余白 / 灰。
**比喻的分寸(硬规矩)**:统计上不显著只写「不显著 / 判不出谁赢」,**不写「打平 / 平局」** —— 不显著不等于证明一样;比分是两组的平均值,不是「谁赢了」。

## 材质与后期
- 底子 `backdrop: 'stadium'`:上半屏人群色点(越往下越淡,下半屏留给内容)、顶边几颗泛光灯小亮点、暗角。草皮、LED 板不在底子里,由 `bc.pitch()` / `bc.led()` 画(第 14 期:LED 板 y=790、草皮从 870 到底,字幕压在草皮上;`ledY` 可调)。
- 无颗粒、无纸纹;LED 板加一层 12px 竖向像素格(不透明度 .025)。

## 字体倾向
- 转播包装字(R1 R2 R6 R9):**思源黑体 900**。队名用同一字体整组 `skewX(-10)` 当斜体(中文字体没有真斜体)。
- 比分与大数字 R4:**Anton**(窄体粗,数字等宽感好);中文单位仍走思源黑体。
- 说明小字 R3 R7 R10:思源黑体 500。
- 原文 R5(论文、新闻稿里的话):思源宋体 500 —— 那是印刷品,不是转播包装。
- 本画风没有手写层:R8 改成黄色小字擦入。

## 组件长什么样
- 文字出场 `wipe`:被遮罩从左擦出来 + 往右滑 24px 落定,0.35s expoOut(R3 / R10 0.3s)。
- 印章 `slab`(黄色实心牌 + 深蓝粗字,甩入落地);批注 `box`(黄色细框);数字 `punch`(变化时轻跳);气泡 `card`(深蓝圆角卡 + 黄色左条);窗口 `win`;面板 `flat`。
- 转播部件在附加模块 `engine/vc/broadcast.js`(第 14 期整片抽出,2026-10-11):`const bc = VC.broadcast(kit, {onCue, onText, ledY})`。草皮 `pitch`、LED 赞助板 `led`、时间标签 `tab`、裁判条 `refBar`、信息条 `infoRow`(黄色标签块 + 深蓝长条)、编号步骤条 `steps`、比分板 `scoreboard`、小比分板 `miniBoard`、斜体队名 `team`、对阵行 `fixture`(划掉的一场用红线)、选拔漏斗 `funnel`、其他赛区结果行 `result`、建议行 `tip`、人点阵 `dots`(493 → 220 变暗)。用法见 engine/vc/README.md「转播」三行。抽完后第 14 期页面改用它,正片 617 帧(每 0.6 秒)和两张封面逐像素相同、音效登记 167 条不变。

## 动效手感
- 包装条都是**擦出来的**(从左往右的遮罩),不淡入、不弹;LED 板换广告 = 整条从左往右点亮 0.6s。
- 镜头之间 `slide-push`(黄色竖条领路,像导播切板),0.5s,在段首前 0.3s 开始。
- 数字只在真实值之间变(`counter`);人数变少用「点阵变暗」而不是滚数字。

## 人物怎么画
- 代码画:不画人;两组用「队」表示(队名牌 + 队色竖条),人数用点阵。
- 生图角色:要的话按「TV sports broadcast graphics, flat navy panels, no logos, no real team names」约束,不出现真实球队、联赛、赞助商标志。
- 代码补光:不补光。

## 能画的场景
整片 ×1(第 14 期,2026-10-11,6 分 10 秒横版):终场比分板、赛事介绍、选拔漏斗、两队规则卡、104 周赛程条、走势曲线(示意)、两个时间点比分板、场外实验、赛后复核三屏(赞助板 / 人点阵 / 对阵表)、世卫裁判组、其他赛区比分、标签特写、战术板、三队队牌。
建议:两种做法 / 两种食物 / 两种工具正面对比的试验;「赞助方是谁」要讲清的题(赞助板是天然位置);多项研究汇总(「其他赛区」)。

## 踩坑
- **看台色点铺满整屏太花**:第一版人群点铺全屏、泛光灯是半径 70 的大灰盘,压在字后面很乱;改成只在上半屏、越往下越淡,泛光灯缩成顶边小亮点。
- **同一 y 的两块包装条 clipPath id 撞了**:页面部件起初按 y 坐标起 id,两块并排的裁判条(第 52 周 / 第 104 周)用的是同一个 id。改成每帧归零的计数器(和 `kit.begin()` 同理)。
- **两套内容在同一镜头里交接时要先退后进**:曲线图淡出和比分板淡入叠了 0.3 秒,检查报叠字。让旧的先退干净、新的再进。
- **擦入的队牌,字要放进同一个遮罩里**:框在擦、字已经整串出现,检查报「字压在素材边上」。
- **短标签别抄字幕**:「连往热饮里加代糖也不行」这类整句上屏就是复述;改成「热饮里加代糖:同样不行」这样的标签式短语(复述从 25 秒降到 3 秒,剩下的是新闻稿原话引用)。
