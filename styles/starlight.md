# 星夜光点(id: starlight)

## 渲染语言
深夜星空:近黑底(#05070D)、中间一团很淡的深蓝星云、固定种子的星点;画面里的「主角」是**会发光的点**和**细线**。
- **光点**(`kit.orb`):暖金的核心量、答案、惊奇;一个光点从一处滑到另一处就是一次揭晓。
- **发光的线**(`kit.glow`):冷蓝(#56769E / #86B6E6)画结构和线稿——数轴、天平、食物、山脊;线宽 1.5–2.5px,不填色,每条线自带两层辉光;画的时候笔尖带一颗亮点(「光把东西画出来」)。
- **铺满画面**:远处几层山脊光线做景深,主体(天平、数轴)横跨大半个画面;不用 UI 卡片框装东西(第一版样片用了卡片框,owner:「素材看的感官一般」)。
- **颜色即含义**:暖金(#F2C27A)只给「这期的核心量 / 答案」;冷蓝给结构;红(#E8646E)只给噪声 / 要警惕的量;其余是暖白(#EEEAE2)和灰(#8C95A8)。
- 留白多、一屏只放一件事;字小而克制,不靠大字压画面。
参考:抖音「Vibe 知识大赏|信息论」(2026-09 发布,约 105 万赞;owner 2026-10-10 让拆解,逐帧看过 30 帧左右)。学的是做法(颜色绑定含义、光点当主角、观众动手),不搬它的素材、标题与系列名。

## 材质与后期
- 星点静止在底子里(`backdrop: 'starfield'`);要「活」就在上面叠 `kit.particles(t)`(缓慢上飘、明灭的微尘,逐帧可复现)。
- 暗角 .55;极轻颗粒 5%(overlay)。
- 光晕:`kit.orb` 自带三层(大半径径向渐变 + 中层模糊 + 白芯);光晕组带 `data-over`,不算「字压素材」。

## 字体倾向
- **思源黑体 300**(R1 / R2 / R4 大字)、**思源黑体 400**(R3 / R6–R10 小字:300 在 30px 以下太虚);英文与数字也走思源黑体。字整组带**霓虹辉光**(`neon: true` ⇒ 组件统一套 `vc-neon`:两层模糊叠在原字下面)。
- 为什么不是宋体:第一版用思源宋体细体,owner 看第二版样片说「上边配的字体有点不搭」;四种字体并排对比(宋体 / 黑体细体 + 霓虹 / 霞鹜漫黑 + 霓虹 / 得意黑 + 霓虹)后定黑体细体 + 霓虹 —— 笔画粗细一致,和发光线稿是同一种东西;宋体的书卷气和霓虹线稿像两套画面(2026-10-10)。
- 原文 R5 仍用思源宋体 300 + STIX Two Text(印刷原件)。
- **Cormorant 斜体只给英文副字幕整行用**(页面自己画,见样片):它的数字是悬挂式的,混进中文句子里像下标(样张第一版实测,已改)。
- 本画风没有手写层:R8 手记改成冷蓝细字亮起。

## 组件长什么样
| 组件 | 造型 |
|---|---|
| 文字出场 `glow` | 从虚到实、从暗到亮(高斯模糊 9→0 + 透明度),不位移、不弹;默认 0.9s,R1 1.1s;出场后保持霓虹辉光 |
| 面板 / 窗口 | 细灰线圆角框(`line`) |
| 批注 | 下划线从左扫到右 + 辉光(`glow`) |
| 印章 | 状态胶囊(`chip`),金边 |
| 数字 | 辉光(`glow`);数轴上的答案用 `numberLine` 的光点滑过去 |
| 气泡 | 细白线圆角气泡 + 尾巴(`line`) |
| 观众动手 | 二选一框、倒数细环、数轴、填空下划线全是细线;揭晓 = 变暖金 + 辉光 |

## 动效手感
- 慢、柔:缓出(cubic out),揭晓的光点滑行 1.2s 缓入缓出;不用回弹、不用甩入。
- 揭晓前留白:问题问完,配音停 3–4 秒(`narration.json` 的 `gapAfter`),画面放 `kit.countdown`,让观众自己先选 / 先猜。
- 转场:镜头之间用 `blur-push`(样片);同一场景里尽量不切镜头,靠新元素亮起、旧元素变暗推进。

## 人物怎么画
- 代码画:不建议画角色;要有「人」就用光点(样片里 20 个光点 = 20 个受试者)。占位角色用 `line` 气泡的画法(实心身子 + 大眼),在星空底上像贴纸,能不用就不用。
- 生图角色:要求「line-art only, thin glowing strokes on near-black, no fill」,再在代码里加光晕。
- 代码补光:暖金光点放在主体背后当光源。

## 踩坑
- `VC.ready(kit, 文字)` 的文字别传整页 `innerHTML`:里面的换行和空格让「画出宽度 vs 应有宽度」的探针全报 0(SVG 会合并空白,canvas 不会)。传真出现在画面上的字。
- 卡片里角标、内容、标签要各包一层 `<g>`:检查器按父节点把同串字合起来量,合起来的大框会压到盘子线稿上,报出不存在的「字压素材」(样片实测一处,`choice` 已改)。
- 辉光滤镜不能按包围盒比例定区域:水平 / 竖直直线的包围盒高或宽是 0,辉光整个消失(第二版样片实测天平横梁没光)。`kit.glow` 用画面坐标的 `vc-bloom` / `vc-bloom-s`。
- 样片没有背景音乐;参考作品的「治愈感」有一半来自环境配乐,正片要配(找可商用的环境乐)。
