# 动态文字(id: kinetic)

## 渲染语言
字就是演员:近黑底(#0E0E10),米白粗字,一个响亮的黄(#FFD23F)+ 一个红橙(#FF4D2E)。关键词踩着配音重音砸进来,落地后钉住不动;画面里除了字几乎没有别的。
适合竖版、清单(../formats/listicle.md)、观点片的开头 3 秒。

## 材质与后期
极轻颗粒、轻暗角(25%)。不加纸纹、不加光效。

## 字体倾向
中文思源黑体 900(主词)/ 500(小字);英文与数字 Anton(OFL,窄体重字);手记用得意黑(斜体感)。没有手写、打字、印刷原件三层。

## 组件长什么样
| 组件 | 造型 |
|---|---|
| 批注 / 划重点 | 红橙色块从左一刷到底,压在字下面,字是白的(`mark: 'block'`)。**黄底上压白字看不清**,色块用红橙 |
| 印章 / 标记 | 黄色实心色板 + 黑粗字,斜 4°,甩入落地(`stamp: 'slab'`) |
| 大数字 | 黄色 Anton 大字,变化时跳一下(zoom punch),只在真实值之间变 |
| 气泡 / 面板 | 无描边扁平色块(沿用扁平几何) |
| 角色 | 双色扁平吉祥物 |

## 动效手感【我们】engine/vc 实现,样张决策者看过
- 主词 **甩入**(`entrance: 'slam'`):6 帧从 1.9 倍砸到 0.94,2 帧回弹到 1,落地震一下(0.15s 衰减),之后钉住不动。
- 小词 **滑入**(`entrance: 'slide'`):4 帧从左 40px 滑到位。
- 签名转场:**fill-zoom**(冲进一个形,形的颜色 = 下一屏底色)、**bands**(三条斜色带接力)。参数与实测见 ../design/camera-transitions.md「共享组件里的转场」。
- **bands 刺激度高**:相邻帧最大跳变 112(slide-push 才 19–21),一期里少用,只给节奏最快的段落切换。

## 人物怎么画
扁平双色吉祥物;这个画风里角色是配角,字才是主角。

## 能画的场景
样张:信息卡片。建议:清单盘点竖版、开头 3 秒、观点片金句。
