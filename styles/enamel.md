# 搪瓷暖水瓶(id: enamel)

比喻:「爸妈家里那张桌子」。适合跟家庭饮食习惯有关、想让观众转给长辈看的题。第一次用:N16(烫茶、烟酒与食管癌,2026-10-14,决策者从三张新画风静帧里选中)。

## 渲染语言
- 平涂 + 一层柔和的横向渐变(搪瓷缸、暖水瓶外壳),不描黑边;投影是一块模糊的深色椭圆。
- 一面长墙:上半白灰墙(#ECE5D3)、下半绿漆墙围(#6E9B84,上沿一道深绿);桌面是红白格子塑料桌布(格子斜切 + 纵向压扁,有透视)。
- 颜色即含义:**搪瓷红** = 要警惕的量;**墙围绿** = 平静、没发现、建议;**深蓝**(铁底 #1F2C45)= 研究机构、观察研究这类中性说明。
- 全屏一层很淡的颗粒(feTurbulence,不透明度 .07)。

## 材质与后期
- 搪瓷:奶白缸身 + 红口沿 + 底部一圈深蓝;**磕掉瓷的地方露出深蓝铁底**(两三个小斑),是这个画风最认得出的细节。
- 暖水瓶:红壳 + 竹编纹(pattern:细波浪 + 竖线);盖子是软木塞色。
- 标牌:奶白底、9px 彩色边 + 内侧一道细线、四角铆钉、一角磕瓷。
- 热气:几缕白色折线 + 高斯模糊;在米色墙上要加一层偏移的灰影才看得见(不加就淡得找不到)。

## 字体倾向
- 标牌大字:站酷庆科黄油体(ZCOOL QingKe HuangYou,像搪瓷标牌上的喷字)——**只给短标题**(「烫茶 + 酒」「烫?」「凉一凉再喝」);它的「多」「九」字形像别的字,含这些字的、长句、数字一律用思源黑体 900。
- 大数字(R4)思源黑体 900;说明字思源黑体 500(40 起,墨色);调查表上的印刷字思源宋体 500 逐字打出;手写是小赖体蓝色圆珠笔(R8)。
- 不出现:书法、等宽代码字(电子仪器读数除外,用 JetBrains Mono)。
- 印章(R9)默认是搪瓷红字盖在奶白底上;红底奶白字的搪瓷小牌由页面自己画、传 `fill`(2026-10-15:原先默认奶白,共享印章在奶白底上几乎看不见,出缩略图时发现)。

## 组件长什么样
- 数字 / 结论 → 搪瓷标牌(`sign`),要强调时整块换成红底奶白字;标牌出场 = 从上面挂下来摆两下(`hang`),配「当」一声。
- 小结论章 → 红色圆角搪瓷小牌(`badge`),落下时放大 1.6 → 1。
- 计数单位 → 小搪瓷缸(10 只 = 十分之一一只,100 只 = 1% 一只;染红表示占比),画面标「示意」。
- 年份 → 挂历(红头、大年份,翻页 = 一页页往上掀)。
- 调查表 → 木硬板夹 + 印刷表格 + 蓝色圆珠笔打勾。
- 对比条 → 圆头搪瓷长条(上面一道高光),长度按倍数,竖虚线 = 基准 1。
- **桌布上不直接写字**(红白格子上的字看不清):一律垫奶白小卡片(`tag`)。

## 动效手感
- 镜头沿墙横移,一段一站(站距 2300px,横移 1.25s eioCubic,段首前 0.35s 开始);段内只有极轻的推近(1 → 1.22)。
- 换地方用「东西里的世界」:镜头推进桌上的一张明信片,明信片画面里就是下一个场景(推进时明信片同步摆正,推到底时 0°,切换不跳);出来用一团热气抹过整屏,中间瞬切(热气最浓时画面全白)。
- 文字出场以「挂下来」和淡入上滑为主,不弹跳。

## 人物怎么画
- 本画风目前不画人:人群用搪瓷缸 / 玻璃茶杯当单位图标。
- 要画人时:建议平涂剪影 + 搪瓷式的高光条,不描边;生图角色需加「flat enamel colors, cream and red, no outlines」并统一投影。

## 能画的场景
- 已实战:家里的长墙与饭桌(N16);明信片里的伊朗茶桌(蓝色八角星瓷砖墙压暗 60%、地毯纹桌布压暗 45%、郁金香小玻璃茶杯、方糖、茶壶)。
- 建议:厨房灶台、菜市场摊位、单位食堂、老式药箱(都是「家里 / 身边的东西」)。

## 踩坑
- 瓷砖、地毯这类满铺纹样必须压暗(本期 60% / 45%),否则字压在上面读不出来。
- check-text-bounds 不认 clip-path:被裁掉、看不见的字照样算进叠字 / 出画。镜头推进「东西里的世界」后,外面那个世界别再画;出来以后,里面那个世界也别再画。
- 挂历年份字号按纸宽算(`min(高 × .42, 宽 × .38)`),不然四位年份会伸出纸外。
- 寒暑表刻度数字放在玻璃管左边、木板里面,放右边会伸出木板(检查器报「字压素材」)。
