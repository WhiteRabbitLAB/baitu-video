# 8-bit 像素(id: pixel)

## 渲染语言
8 位游戏画面:**低分辨率像素画**(一个像素 = 屏幕上 4px,逻辑画布 480×270 放大 4 倍)、**有限色板**(16 色左右)、天空分几条色带,交界处用棋盘格**抖动**过渡。
不描矢量边线、不用圆角、不用渐变、不用模糊;明暗靠换一格颜色(亮面一块、外圈一格深色描边)。
**比喻是「一局游戏、一关」**:年代 / 阶段 = 关卡(「白垩纪 · 最终关」),数量 = 生命值 / 分数,旁白 = RPG 对话框,意外 = 「!」。适合地球史、进化、「一步步升级 / 失去」的题,以及怀旧题材。
**颜色即含义**:黄 #FFD27A 只给「要看的那个」(分数、名牌、印章);红 #E0505A 给危险 / 失去(批注、扣掉的心);青 #8FD3FF 是「系统提示」;其余暖白。

## 材质与后期
- 底子 `backdrop: 'pixel'`:天空四条色带(`c.sky`,深蓝紫往下渐暖),交界处 8px 高的棋盘抖动(`vc-dither-<i>`,每条带一个);上半屏固定种子的 4px 星点;整屏时底部 14% 是草地 + 泥土(地面在 86% 高,吉祥物脚底对齐)。
- 无颗粒、无暗角(`vig: 0`)—— 真机画面没有这些。
- 页面自己画的像素美术:按 4px 网格画(坐标、尺寸都取 4 的倍数);形状先画进遮罩再统一描一格深色外边(静帧 `brief/style-explore/d.js` 有一个 `sprite()` 写法可抄)。

## 字体倾向
- **全部角色都是 Fusion Pixel 12(缝合像素字体,中英同一套)**;字号只能是 12 的整数倍(`pixel: 12`,kit 自动吸附:24 / 36 / 48 / 72 / 96)。12 × 4 = 48 时字的笔画和美术像素同一大小,首选。
- 不出现:手写体、宋体、细体 —— 这个画风里没有「纸」也没有「笔」。
- 频道字幕可以照常压在底部;更像这个画风的做法是把旁白放进 RPG 对话框(静帧 D 就这样做),两种选一种,不要同时出现。

## 组件长什么样
- 文字出场 `type`(逐字出现,RPG 打字);批注 R6 `blink`(亮灭亮灭亮,0.4s 后定住)。
- 批注 `pixbox`:先出四个角括号、再连成整框,4px 线;印章 `pixbadge`:黄底切角像素牌 + 右下硬阴影,三步放大(.6 → .85 → 1)落定;数字 `punch`。
- 气泡 `rpg`:深底 + 内侧一圈 4px 亮边 + 台阶状小尾巴,分两步弹出;说完右下角黄色 ▼ 闪。窗口 / 面板 `rpg`:同一造型,标题是压在左上边上的名牌。
- HUD(关卡名、生命值的心、分数)放在顶上一条深色带里 —— 页面自己画,静帧 D 有。

## 动效手感
- **步进,不缓动**:出现 = 闪 / 分两三步放大;移动按整格(4px)跳,帧率感 12 fps 左右(页面里把时间取整到 1/12 秒再算位置)。
- 转场:整屏「像素溶解」(按 8–16px 方块随机翻成下一屏)或黑屏切换 —— 还没做进引擎,第一期用时补;暂时用 `fade` 硬切也不出戏。
- 数字只在真实值之间变(`counter`)。

## 人物怎么画
- 代码画:适合。人物、动物都按 4px 网格画剪影 + 一格深色外描边 + 一块亮面(静帧 D 的霸王龙、三角龙)。占位角色 `mascot` 在这个画风里按 8px 方格栅格化。
- 生图角色:「8-bit pixel art sprite, limited 16-color palette, 1px dark outline, no anti-aliasing, transparent background」,出图后最近邻缩到逻辑尺寸再放大 4 倍,把半透明边一律吸到色板上。
- 代码补光:不补光;要夜晚 / 火光就整块换色板,不叠渐变。

## 能画的场景
整片 ×1(2026-10-12,12 分钟横版长片:五关、每关一组角色按时间排队,旁白整句进 RPG 对话框,一条按原因上色的进度格贯穿全片,8-bit 方波音效 + 代码合成的背景乐;像素层画在 canvas 上,字一律走 SVG)。
静帧 ×1(2026-10-12,恐龙灭绝:分带天空、火山、霸王龙、三角龙、小行星拖尾、HUD、对话框)。
建议:地球史 / 进化(关卡 = 地质年代)、「血量」式的身体资源题、技术史(像素画天生是早期电子游戏的年代感)、清单题(每一项 = 一关)。

## 踩坑
- **画布绘制的字检查不到**:静帧 D 的字画在 canvas 上,`check-text-bounds` 只认 SVG `<text>`,扫出 0 处是假的。正片里字一律走 kit(SVG),美术可以用 canvas 或 SVG 方块。
- **脚底要贴地**:第一版霸王龙脚底离地 6 个像素(24px),一眼就像飘着;像素画里差一格都看得见。
