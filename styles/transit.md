# 地铁线路图(id: transit)

## 渲染语言
城市地铁线路图:**米白底**、**粗彩线**(14–18px)**只走横竖和 45°**、普通站 = 白圈黑边、换乘站 = 更大的黑粗圈、站名**中英双语**(中文黑体、英文 Space Grotesk 小一号灰色)。
平涂、无渐变、无投影;河 / 海也只走横竖和 45°(像伦敦地铁图的泰晤士河),浅蓝。
**比喻是「一段路要换乘」**:流程的每一步 = 一站,换了一种机制 / 介质 = 换乘,要走的那条线上色、同一张网里的其他线**压成浅灰**。适合「一样东西怎么走到那儿」:消息、快递、电流、食物在身体里、一个想法怎么变成产品。
**颜色即含义**:每条线一种颜色(橙 #EF7D1A / 蓝 #1F6DB5 / 绿 #2A9D5C,图例里写清每种颜色是哪一段);红 #D6312B 只给「你在这里」和要警惕的量;其他线路灰 #C9C6BD。

## 材质与后期
- 底子 `backdrop: 'transit'`:米白 + 很淡的「整张网」(几条灰线、几个白圈站,不透明度 .38),只当纹理,不抢内容;页面要画真线路时盖在上面。
- 无颗粒、无暗角(`vig: 0`)—— 印刷地图的干净感。

## 字体倾向
- 全部是**黑体**:标题 / 站名思源黑体 900 或 600,说明 500;英文、数字 **Space Grotesk**(700 / 500)。
- 原文 R5 用思源宋体 500(那是印刷原件,不是站牌字)。
- 本画风没有手写层:R8 改成蓝色「站内提示」小字。不出现手写体、衬线大标题、像素字。

## 组件长什么样
- 文字出场 `wipe`(像站牌条从左擦出);批注 R6 `pop`。
- 批注 `route`:**字底下画一段线路**,从左画到右,起点一站、画到头再亮终点站 —— 这个画风的签名部件。
- 印章 `capsule`:线路色胶囊牌、白字(像线路编号牌);数字 `punch`;气泡 `flat`:黑底白字圆角站牌(`c.bubble`)。
- 窗口 / 面板 `legend`:图例牌 —— 白底黑边圆角框,标题条是黑底白字站牌,左头一枚线路色小方块。
- 页面自己画的线路部件(静帧 A 有):`line(points, 颜色)` 折线、`stop` 普通站、`xfer` 换乘站、双语站名、「你在这里」红色定位针 + 红牌、海底 / 隧道段(彩线中间一条白虚线)、图例、标题牌。

## 动效手感
- **线是画出来的**:线路沿着走向从起点长到终点(stroke-dashoffset,匀速略带缓出),每到一站站点弹出一下(0.15s);一节「列车」(圆角小车,里面装着那样东西)沿线移动,到换乘站停一下。
- 镜头跟着列车平移;一屏讲一段线,换乘 = 换段落。
- 转场:沿线路方向 `slide-push`。

## 人物怎么画
- 代码画:不画人;「你」= 红色定位针,「那样东西」= 列车里的图标(对话气泡、包裹、食物)。占位角色 `mascot` 是扁平橙色圆身子。
- 生图角色:不需要。真要放人,用地铁导视里的标准人形图标那种剪影(单色、无五官)。
- 代码补光:不补光。

## 能画的场景
**整片 ×1(2026-10-13,A11 信息论入门,约 4′40″,23 版)**:一道是非题 = 一个岔口,「是」走橙线、「不是」走蓝线;二叉线路网当开场与封面、数轴线路(1 到 100)、站点挨个打红叉、只剩一站的终点 + 定位针、同一条线路上 5 站 = AI 问的 5 道题、虚线站 = 没问到的。页面自写部件:`line`(沿走向长出来)、`stop`(到站弹一下)、`fork`(先 45° 再横走)、`tree`(二叉网)、`train`、`sign`(黑底标题牌)、`cap`(线路色胶囊)。
静帧 ×1(2026-10-12,一条消息怎么走:你的手机 → 基站 → 运营商机房 → 聊天服务器 → 海底光缆 → 对方手机,其余网络压灰)。
建议:流程 / 因果链科普(快递、电力、互联网、供应链)、身体通路(食物 → 胃 → 小肠 → 血液 → 肝)、「一条路有好几种走法」的对比(两条线路并行,哪条更快)、历史路线(丝绸之路、迁徙)。

## 踩坑
- **字号**(A11,沿用报纸号外 N15 的教训):角色默认字号 2026-10-13 起调大(R3 42 黑字、R10 30、R2 60),图例牌 `legend` 栏题 26 → 38;站名只写中文、44 号起,双语小字在视频里读不了,不放。
- **底纹会被当成「字压素材」**(A11):底子那几条很淡的灰线让检查器报了 50 处;底纹现在带 `data-over`,检查器不算。页面自己画的线路**不要**加 `data-over`,字压线要能查出来。
- **画面上的假设数字别早于口播的假设**(A11 复核):「是 1% / 不是 99%」在口播说「假如一百样机会都一样」之前就出现,等于把假设说成了事实;之前只写「机会很小 / 很大」。
- **站名和线路抢位置**:静帧第一版「运营商机房」压在灰线上、「Far landing」被灰色斜线穿过、列车盖住了「Cable landing」。站名先定、线后画;斜线的起点往外挪一站;列车停在两站正中。`check-text-bounds` 不带 `--objects` 查不出字压线,要带上。
- **只走横竖和 45°**:随手画的斜线(30°、60°)一出现就不像地铁图了;连河也要折成 45°。
