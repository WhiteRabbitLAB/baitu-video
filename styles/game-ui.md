# 游戏拟物(id: game-ui)

## 渲染语言
像一款真游戏的截屏:精致的深色面板 + 金边、地形有材质(草地、平原、雪山、喀斯特、海)、羊皮纸古地图做未探索区。
**要求游戏级精致度,粗糙就不成立**(决策者原话:既然用文明的感觉就别做得太粗糙)。

## 材质与后期
金边面板(渐变描边 + 内阴影)、羊皮纸、地形纹理、迷雾、单位旗布料感。

## 字体倾向
游戏标题字(站酷小薇)+ 界面无衬线(思源黑体);历史原文用刻本宋体;古地图地名用毛笔。

## 组件长什么样
回合横幅、成就条、单位面板、城市名牌、资源计数器、历史时刻卡、顾问对话框(金框头像)、小地图、「下一回合」按钮。

## 动效手感
面板滑入、横幅展开、成就弹出、迷雾一格格翻开、数字滚动;每段解锁一种新机制。

## 人物怎么画
- 吉祥物进金框头像当顾问。
- 单位立绘适合生图(未试):与 UI 同光源,描边风格与图标一致。

## 能画的场景
已实战:策略游戏(strategy-game)。建议:RPG 任务日志、模拟经营、卡牌对战。

## 踩坑
站酷小薇字形缺陷(见 ../design/fonts.md);地图只示意、只标地名不画边界。
