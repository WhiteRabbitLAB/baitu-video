# 画风路线图(长期更新)

画风库会一直长。这里管三件事:**候选清单、入库标准、更新节奏**。

## 入库标准(三张样张,缺一不入库)
1. **空场景样张**:用一个已有场景(建议 field-notebook 或 info-cards,内容固定方便横向比)按新画风重画一帧。
   出图工具:在 `engine/vc/styles.js` 加一套外观后跑 `node engine/vc/samples.mjs <id>`,一次出三张(空场景 / R1–R10 / 角色)到 `samples/`。
2. **文字角色样张**:R1–R10 在这个画风里各一行,字体、承载物都要出现(检验「字跟着画风走」)。
3. **角色样张**:吉祥物或一个生图角色放进去,按画风补光调色后不像贴纸。

三张都过决策者⇒ 在 INDEX.md 登记为「样张」;用在一期成片里 ⇒ 改「整片」。
每个画风在 INDEX 里配一张缩略图(使用者靠看图选,不靠读文字);现有 11 种已出(2026-10-07 起,`engine/vc/thumbs.mjs`),新画风入库时在 `engine/vc/styles.js` 加一套外观再重跑。

## 更新节奏
- **每做一期,至少验证一个新组合**(新画风 × 已有场景,或已有画风 × 新场景),顺手出三张样张。
- 没有片子在做时,按优先级从上往下补样张;一次只做一个,做完再下一个。
- 外部看到好作品:先记进 ../catalog/references.md,判断能不能做,再决定是否进这张候选表。

## 新增一个画风的完整步骤
1. 在本表加一行(候选)。
2. 复制 `_template.md` 写画风卡(必写「人物怎么画」)。
3. 出三张样张 → 决策者看 → 在 INDEX.md 登记 + 缩略图。
4. 字体缺什么就在 ../design/fonts.md 补;组件长什么样在 ../design/components.md 加一列。
