# 报纸号外(id: newsprint)

## 渲染语言
老报纸版面:**新闻纸**(米黄 #EBE3CF、纤维颗粒、一道横向对折的折痕)、**黑油墨 + 一个红**、思源宋体大标题、**粗细双线**分栏(顶上一粗一细、栏与栏之间一根竖细线)、照片一律 **45° 网点**。
无圆角、无投影、无渐变(除了折痕和四边发黄);层次靠线和字号,不靠色块。
**比喻是「这件事在当时就是头条」**:历史事件、翻案、更正都能讲;**更正启事、电讯稿、号外、读者来信**是这个画风天生的部件(「当年报纸这么写 → 后来更正」正好是辟谣题的结构)。
**颜色即含义**:红 #C3241B 只给报头「号外」、校对红笔、印章;其余全是黑墨。

## 材质与后期
- 底子 `backdrop: 'newsprint'`:纸色 + 颗粒(正片叠底 .2)+ 中间一道折痕(`vc-fold`:暗—亮—暗三条);四边发黄用暗角 `vig: .22`。
- 网点图案 `vc-ht-news`(9px、45°、黑墨点);照片 / 插图的做法见静帧 C:先在离屏 canvas 上画灰度图,再按 45° 网屏取样,点的面积正比于暗度(半径 = 格距 × 0.6 × √暗度)。
- 整版可以轻微转 0.5–1°(像拍在桌上的一张报纸),四角露出深色桌面。

## 字体倾向
- 标题 R1 R2、大数字 R4、印章 R9:**思源宋体 900**。正文 R3 R7 R10:思源宋体 500。
- 原文 R5:电讯稿 —— 中文宋体 500、英文 **Special Elite**(电传打字机),逐字打出,带轻微墨色深浅。
- 手写只有两种:校对红笔 R6(**智勉行**,红,正片叠底)、读者在报上写的圆珠笔 R8(**小赖**,蓝黑)。
- 报头的英文「Extra」可以用 UnifrakturMaguntia(哥特体);这只是页面上的报头,不进角色表。
- 不出现:黑体大标题(会像网页)、像素字、霓虹。

## 组件长什么样
- 文字出场 `fadeUp`;原文 `type`;红笔 `hand`。
- 批注 `pencil`(红铅笔圈,正片叠底);印章 `ink`(红色油墨章,落下一下);数字 `print`(变化时下面一条红色划线)。
- 气泡 `quote`:报纸引语 —— 不画框,左边一条红竖线 + 上下两道细线,纸色垫底。窗口 / 面板 `column`:专栏 —— 顶上一粗一细两道线、栏题宋体、栏题下一道细线、底下一道细线。
- 版面部件(页面自己画,静帧 C 有):报头 + 左右两耳、日期线(双线夹一行)、通栏大标题 + 副题、竖栏正文、引语、「另讯」小栏、网点照片 + 图注。

## 动效手感
- 慢、稳:字淡入、电讯稿逐字打;不弹不甩。镜头在一张报纸上**平移 / 推近**(像镜头扫过版面),一屏一件事。
- 转场:经典的「报纸转着飞进来」只在开头用一次(抖音上很容易显得土);段与段之间用翻页或横移。都还没做进引擎。
- 数字只在真实值之间变。

## 人物怎么画
- 代码画:人物、实物都画成**网点照片**(灰度示意图 → 网点),图注写明「示意」;不画线描卡通。占位角色 `mascot` 在这个画风里身子是网点、叶子是唯一的红。
- 生图角色:「black-and-white newspaper photograph, coarse 45-degree halftone, high contrast, 1960s press photo」,再自己过一遍网点化,保证点的大小和版面一致。**不能**生成冒充真实历史照片的图 —— 一律标「示意」。
- 代码补光:不补光;明暗只靠网点大小。

## 能画的场景
静帧 ×1(2026-10-12,1969 登月号外:报头、日期线、通栏标题、网点照片、电讯正文、引语、另讯)。
**整片 ×1(2026-10-12,N15,一部辟谣题,7′30″,19 版)**:每段一版、段间横推;顶上一条小报头(红「号外」+ 本版标题 + 版次 + 粗细双线);部件:更正启事(流言一行被红笔划掉 + 「更正」章)、本报讯专栏、另讯小栏、读者来信(引语 / 圆珠笔)、网点横条 / 竖柱图表、本报提示清单。
建议:历史事件纪实、「当年怎么报 → 后来怎么更正」的辟谣题、实验纪实(当年新闻报道这个实验)、人物故事(讣告 / 人物专访版式)。

## 踩坑
- **字要比真报纸大得多**(N15 决策者看片:「很多字太小,感官不好」):照真报纸排密的小字,在视频里读不了也不好看,报纸感靠纸、双线、网点和大标题就够了。下限(2026-10-12 起是画风默认值):说明 R3 ≥ 42 且黑墨(不用灰)、栏题 46、图注 / 出处 R10 ≥ 30、红笔 R6 ≥ 64、通栏标题 110–140、主数字 ≥ 130;一版只放 4–6 行字,铺满 200–900 的版心。
- **网点照片要「先画对比度」**(N15):灰度示意图里主体和底的亮度差不够,网点化后糊成一片(第一版的主体认不出)。做法:底子压暗(#555 上下)、主体要么很亮(#f7)要么很黑(#1c),再给亮物件加 4–5px 深色描边;叶脉、茎用亮线。小图(< 500px 宽)细节基本看不见,只留轮廓。
- **数字别用滚动计数器**(N15):`counter` 从 15.8 滚到 4.7 的那 0.1 秒,逐位滚动会被检查器判成两串数字叠字。报纸画风的做法更自然:旧值一行、红笔划掉,新值另起一行。
- **印章旋转别太大**(N15):`stamp` 落下那一帧放大,-8° 时章的内框会擦到自己的字(检查器报「压素材」);-4° 就不会。
- **图表条长要么按真实比例,要么标示意**(N15 复核):184 / 14 / 7 三根条第一版没按比例也没标,改成按对数成比例。
- **网点照片第一版糊成一片**:点半径按「格距 × 0.72 × √暗度」算,中灰就几乎铺满,登月舱和宇航员都看不出来。改成 0.6,并把源图的主体画亮、画大(主体占照片高度一半以上)。
- **数字不能跨行拆开**:竖栏按字数折行时把「11 号」拆成了「1 / 1 号」。折行按「ASCII 串整体不拆」算宽度,行首不放标点。
- **不仿真实报纸**:报头只写「号外 / Extra」,不用任何真实报纸的名字和版式标志。
