# 白板手绘(id: whiteboard)

## 渲染语言
近白的白板底(#F8F8F5),马克笔线稿:黑(主线)、蓝(讲解与数字)、红(批注、圈重点)、绿(备用);线宽 4.5–7px,一笔画成、首尾略出头,有固定种子的轻微抖动。
面不平涂,用**斜线排线**表示明暗 / 强调;**一切都是当着观众画出来的**(边讲边画),最后可拉远看到整块板。

## 材质与后期
白板底 + 擦过没擦干净的淡痕(灰色宽线,不透明度 2.2%);整屏时加一圈铝框。基本无暗角(6%),不加颗粒。

## 字体倾向
三种,全部 OFL(../design/fonts.md):
- 标题 / 大字 / 大数字 / 标记:霞鹜漫黑 LXGW Marker Gothic(马克笔黑体)
- 讲解字、手记、对白、批注、原文抄写:清松手写体 1
- 等宽(终端):JetBrains Mono
数字和英文用这两款中文字体自带的字形;**别用 Gochi Hand 写数字**:它的 5 像 S、7 带横杠,认不清(2026-10-07 样张)。英文版的手写英文再换 Gochi Hand。
没有打字机、印刷原件这两层——白板上一切都是手抄的。

## 组件长什么样
| 组件 | 造型 |
|---|---|
| 面板 / 窗口 | 手画歪框(`VC.wobblyRect`),标题手写在框上沿,下面一条蓝色手画线 |
| 气泡 | 手画框 + 两笔尾巴,先画框再出字 |
| 印章 / 标记 | 红字 + 马克笔一笔圈起来的歪框(先写字后圈) |
| 批注 | 红色马克笔圈 |
| 大数字 | 蓝色马克笔黑体,只在真实值之间变 |
| 角色 | 线稿一笔笔画出来,右半边排线当暗面 |

## 动效手感
- **逐笔画出**:`kit.sketch(路径, t, t0, 时长)`,笔尖跟一支马克笔(笔帽颜色 = 墨色);多条路径按长度分配时长,一笔接一笔。
- **排线**:`kit.hatch(...)`,斜线一条条画进去。
- 字按 R8 手写规矩逐字写出(角度 ±2°、上下 ±3%、大小 ±4%)。
- 转场偏好:同一块板上 **pan-next**(横移到板的下一块),或画满后**整板拉远**;概念推进用 **morph**。不用淡化。

## 人物怎么画
- 代码画:吉祥物线稿 + 排线(`kit.mascot` 白板分支),一笔笔画出来本身就是表演。
- 生图角色:要求「黑色马克笔线稿、白底、无填色、线宽均匀、可有斜线排线」,拿到后去底只留线。
- 不需要补光:白板没有光影,只有排线。

## 踩坑
- 擦痕太浓会像脏(第一版 4.5% 不透明度被自己否掉,改 2.2%)。
- 批注默认色要单独设(`c.mark` = 红),否则跟着强调色变成蓝圈。
