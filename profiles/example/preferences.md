# 决策者偏好示例

> 作者私有内容,仅作示例,见 [LICENSE.md](LICENSE.md)。看写法,换成你自己的。

## 选题
- 有故事、够长、反常识;离奇的真实实验和人最受欢迎;「某营养素 / 某食物来龙去脉」嫌常规。(2026-10)
- 营养类要带实用建议;借热梗只蹭热度,正文不必和梗有关。(2026-10)
- 不要纯新闻(发布会、招股书);要能自己动手做、有意思、成本不高。(2026-09)

## 包装
- 前 3 秒放最好看的画面 + 最反常识的一句话,第 0 帧就是成品;标题说观众,不说主角。(2026-10)
- 封面:真东西满版、展签式排版、少色、无发光无箭头;AI 生图不上封面;「黑底发光字 + 歪卡片 + 箭头」= 太 AI。(2026-10)
- 竖版只在选了竖版平台时做,且按竖屏重新排版。(2026-10-07)

## 画面
- 字体按书写来源选(谁、在什么场合、用什么工具写的)。(2026-10)
- 不用 SVG 抖动滤镜;关键字 ≥ 约 28px;游戏风「别做得太粗糙」。(2026-10)
- 审美示范必须真的好看,否则自我拆台。(2026-10)

## 内容与语气
- 不对观众讲制作方的内部迭代(旧版 / 改前改后)。(2026-10)
- 用法类内容必须有实测,实测先预注册,按实际结果改稿。(2026-10)

## 工程习惯
- 每步做完删自己的中间文件;shell 里不用变量拼路径做 rm。(2026-10)
- 生图角色表演:出图前先列动作衔接表。(2026-10-07)
