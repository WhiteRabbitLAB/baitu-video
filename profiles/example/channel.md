# 频道配置示例:一个营养科普频道

> **这是示例,用来看「填好是什么样子」。** 结构和写法可以照抄;**兔子形象与本文件夹里的偏好是作者私有的,不授权任何使用**,见 [LICENSE.md](LICENSE.md)。请复制 [../_template/](../_template/) 填你自己的。

## 频道
- 营养科普,中文。每期先问发布平台(横版:YouTube / 长视频平台;竖版:抖音),只出选中的画幅;竖版按竖屏重新排版,不从横版裁(../../pipeline.md §0、§9)。
- 决策者:频道主。看样片(段 1–2)说「继续 / 做整片」才做整片;画风动手前先对齐。
- 频道三条标准:故事有意思 / 对观众有用 / 有干货;不要「讲一堆道理,最后摆一个不太合格的结果」。

## 吉祥物:兔子(作者私有,仅作示例)
- 造型权威 `assets/bunny/review-light.png`(六角度设定图;服装以 `bunny-apron.png` 的黑围裙为准;六个姿势 `pose-1…6.png`):圆头、两只竖椭圆黑眼偏低、无鼻无嘴无腮红、胶囊 / 梨形身、细胳膊。
- 否决过:方头正脸、单眼纯侧脸、突嘴和鼻子、照设定图手写 SVG(比例不对)、吃惊放大黑眼珠(像鬼)、硬边高光。
  → **「否决过」这一栏最值得照着写**:每次决策者否掉一个造型就记一行,下次不会再犯。
- 实现:代码几何(径向渐变明暗),每期按场景换身份:探员(档案)、顾问(游戏)、实验室助理(实验室、看板)。

## 频道统一的视觉
- 字幕:思源黑体 900 52px 白字黑描边;每行 ≤ 20 字(不计空格),句中逗号换空格,句末标点去掉、问号保留;只把「带计量单位的数值」转阿拉伯数字,其余保留中文(每期一张转换表,交决策者过目)。
- 章节进度条:成片 > 3 分钟必须有;底部常驻、分章节、当前段高亮、按进度填充;章节与发布文案同源;避开字幕区。
- 品牌底色(马卡龙):#E4ECE3、奶油 #FBF6EC、蛋黄 #F2C14E、粉 #F3B2B0、叶绿 #8DBF8B、薄荷 #A8D8C5、麦色 #D9B98C、墨 #1F1C1A。

## 工具链
用引擎:`new` → `narrate` → `subs` → `fonts` → `render --ranges`(样片)→ `render` → `mix` → `cover` →(选了竖版平台)`vertical` → `accept` → `clean`,命令说明见 ../../engine/README.md。
逐步命令对应 ../../pipeline.md 的每一步。页面契约(渲染器依赖):`window.render(t)`(只由时间决定)、`DUR`、`CUES`、`renderSfx`、`fontsReady`、`FONTS`;封面 `coverReady`;竖版 `vertFrame(t)`。

## 平台规矩
- 抖音:画面、口播、字幕、描述、封面不出现网址与「官网 / 网址 / 网站 / 博客 / 发布页」(实际被限流过);出处写机构名。交付前 grep。
- 地图只示意、只标省名,不画行政边界与国界;不画真人肖像;自伤细节不进稿;热梗原声不用(限流 / 版权),用自己的 TTS 换音色模仿。

配音见 [voice.md](voice.md);决策者偏好见 [preferences.md](preferences.md)。
