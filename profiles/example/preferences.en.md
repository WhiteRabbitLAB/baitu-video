## Topics
- A story, enough length, counter-intuitive; bizarre real experiments and people do best; "the history of nutrient X / food Y" is too ordinary. (2026-10)
- Nutrition episodes must end with practical advice; a trending meme is only a hook — the body doesn't have to be about it. (2026-10)
- No pure news (launch events, IPO filings); it should be something we can do ourselves, interesting, and cheap to make. (2026-09)

## Packaging
- First 3 seconds: the best-looking frame plus the most counter-intuitive line; frame 0 is already finished. Titles talk about the viewer, not the subject. (2026-10)
- Thumbnail: a real object filling the frame, museum-label layout, few colors, no glow, no arrows; no AI-generated images on thumbnails; "glowing text on black + tilted cards + arrows" = too AI. (2026-10)
- Vertical version only when a vertical platform is chosen, and re-laid out for vertical. (2026-10-07)

## Visuals
- Choose fonts by who wrote the text, where, and with what tool. (2026-10)
- No SVG jitter filters; key text ≥ ~28 px; game style must "not look rough". (2026-10)
- An example meant to show good taste must actually look good, or it undercuts the whole point. (2026-10)

## Content and tone
- Never tell viewers about our internal iterations (old version / before vs after). (2026-10)
- How-to content needs real tests, pre-registered, and the script follows the actual results. (2026-10)

## Working habits
- Delete your own intermediate files after each step; never build `rm` paths from shell variables. (2026-10)
- Generated-image character acting: list the pose transitions before generating. (2026-10-07)
