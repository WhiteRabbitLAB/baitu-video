# 频道配置:<频道/系列名>

一个频道的固定设定。skill 的其他部分是通用的;**凡是只属于这个频道的东西都写在这个文件夹里**。
新用户:把整个 `_template/` 复制成 `profiles/<你的频道>/`,三个文件分别填写。写法参考 [../example/](../example/)。

| 文件 | 管什么 |
|---|---|
| `channel.md`(本文件) | 频道、角色、统一视觉、工具链、平台规矩 |
| [voice.md](voice.md) | 配音:用哪家语音、哪个音色、语速、密钥放哪 |
| [preferences.md](preferences.md) | 决策者偏好:说过的喜欢与否决,一条一行、带日期 |

## 频道
- 平台(横版 / 竖版各发哪)、目标观众、选题方向与标准。
- 决策者是谁(谁看样片、谁拍板)。

## 吉祥物 / 固定角色(可选,不要可以删掉这一节)
- 造型权威(设定图路径,放在本文件夹的 `assets/` 里)、否决过的造型、在各场景里的身份。
- 实现方式(代码画 / 生图零件 / 贴图)。
- **请用你自己的角色**。`example/` 里的兔子是作者私有形象,不授权任何使用(见 ../example/LICENSE.md)。

## 频道统一的视觉(不随场景和画风换)
- 字幕:字体、字号、颜色、描边 / 底框、每行字数上限、数字转换规则。起步可以用:思源黑体 900(`Noto Sans SC:900`)、52px、白字黑描边 10px、底边 y=1040;每行 ≤ 20 字(英文 ≤ 42 字符)。页面里用 `kit.subtitle(t, SUBS, {font, size})` 画,`new` 建的起步页已经写好。
- 章节进度条:何时出现、位置、样式。
- 品牌色板、片尾卡、角标。

## 工具链(本频道的实现)
逐步命令,对应 ../../pipeline.md 的每一步;页面契约(渲染器调用页面的哪些接口)。

## 平台规矩
- 各平台的禁忌(网址、地图、肖像、版权音频……)与出处。
