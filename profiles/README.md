# 频道配置 / Channel profiles

| 文件夹 | 用途 | 公开 |
|---|---|---|
| `_template/` | 空模板,新频道复制它 / blank template — copy it for a new channel | ✅ |
| `example/` | 填好的示例,看写法 / filled-in example | ✅ 但兔子与偏好**保留所有权利**,见 `example/LICENSE.md` |
| 其他文件夹 | 作者自己在用的频道配置 / author's own working profiles | ❌ 私有,不进开源版 |

每个频道一个文件夹,三个文件:`channel.md`(频道、角色、视觉、工具链、平台规矩)、`voice.md`(配音)、`preferences.md`(决策者偏好)。英文版同名加 `.en`。
One folder per channel, three files: `channel.md`, `voice.md`, `preferences.md`. English versions use the `.en.md` suffix.
